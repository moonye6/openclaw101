# 上下文分层索引

> 目的: 避免将所有信息堆叠在单个文件中，使用 Tier 1/2/3 渐进式披露。
> 上下文利用率目标: **< 40%**

## Tier 1 — 始终加载 (< 500 tokens)

每次 Agent 会话**必须**加载的核心文件:

| 文件 | 用途 | 大小估算 |
|------|------|---------|
| `AGENTS.md §1-2` | 项目概览 + 架构约束 | ~300 tokens |
| `progress.json → current_session` | 当前任务状态 | ~100 tokens |

## Tier 2 — 按需加载 (任务相关)

根据当前任务选择性加载:

| 类别 | 文件 | 何时加载 |
|------|------|---------|
| **数据** | `src/data/*.ts` | 修改/新增数据内容时 |
| **组件** | `src/components/**/*.tsx` | 修改/新增 UI 组件时 |
| **测试** | `tests/e2e/*.spec.ts` | 添加/修复测试时 |
| **功能列表** | `feature_list.json` | 规划新功能或检查完成度时 |
| **翻译** | `src/i18n/*.json` | 国际化相关任务时 |
| **API** | `src/app/api/**` | 修改后端 API 时 |

## Tier 3 — 深度参考 (仅调试时)

| 文件 | 何时加载 |
|------|---------|
| `next.config.ts` | 调试构建/部署/安全头 |
| `src/lib/db/*` | 数据库 schema/连接问题 |
| `playwright.config.ts` | E2E 测试配置问题 |
| `tsconfig.json` | TypeScript 编译错误 |
| `package.json` | 依赖版本冲突 |

## 加载规则

1. **新会话开始**: 只加载 Tier 1
2. **接收任务**: 根据任务类型加载 Tier 2 相关文件
3. **遇到错误**: 加载 Tier 3 中的相关配置文件
4. **估算当前占用**: 累计已加载文件的 token 数，确保 < 40%
